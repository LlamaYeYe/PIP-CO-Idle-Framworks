# PIP-CO-Idle-Framworks
PIP-CO Idle Framworks V1.0.0 adds automatic idle screensavers to the Wand Company Pip-Boy 3000. It works independently, but if Mesmetron 3000A is installed, it automatically detects and adds its screensavers for preview and 2-minute idle use. Mesmetron’s extra Knob 2 speed/mode controls remain available through the Mesmetron holotape.
